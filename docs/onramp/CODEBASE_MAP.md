# Codebase Map — Healthchecks

Generated by the `map-codebase` OnRamp skill.

## What This App Does

Healthchecks is a Django web application that monitors cron jobs and
scheduled tasks: a job pings a unique URL after each successful run, and
Healthchecks alerts configured integrations (email, Slack, Signal, etc.) when
a ping is late or missing.

## Test Conventions

### Base class: `hc/test.py:24 BaseTestCase`

`setUp()` creates:

| Attribute | Value |
|-----------|-------|
| `self.alice` | Normal user, owns `self.project` |
| `self.project` | Alice's project, `api_key="X"*32`, `ping_key="p"*22` |
| `self.profile` | Alice's `Profile` |
| `self.bob` | Member of Alice's project (REGULAR role) |
| `self.charlie` | Unrelated user — should have no access to Alice's checks |
| `self.csrf_client` | `Client(enforce_csrf_checks=True)` |

Custom assertions:

| Method | Checks |
|--------|--------|
| `assertEmailContainsText(fragment)` | `mail.outbox[0].body` |
| `assertEmailContainsHtml(fragment)` | `mail.outbox[0].alternatives[0]` (HTML) |
| `assertEmailContains(fragment)` | Both plain text and HTML |
| `assertEmailNotContains(fragment)` | Absent from both |

### Test file pattern

```
hc/<app>/tests/test_<feature>.py
```

Each file defines one `TestCase` class. `setUp()` calls `super().setUp()`, then
adds the objects specific to that feature.

### Example skeleton

```python
# hc/api/tests/test_ping.py:16
@override_settings(S3_BUCKET=None)
class PingTestCase(BaseTestCase):
    def setUp(self) -> None:
        super().setUp()
        self.check = Check.objects.create(project=self.project)
        self.url = f"/ping/{self.check.code}"

    def test_it_works(self) -> None:
        r = self.client.get(self.url)
        self.assertEqual(r.status_code, 200)
        self.assertEqual(r.text, "OK")
```

## Run Commands

All commands use the `.venv` virtualenv on Windows.

```powershell
# Activate venv
.venv\Scripts\activate

# Run full test suite
.venv\Scripts\python.exe manage.py test

# Run one app
.venv\Scripts\python.exe manage.py test hc.api

# Run one test class
.venv\Scripts\python.exe manage.py test hc.api.tests.test_ping.PingTestCase

# Run one test method
.venv\Scripts\python.exe manage.py test hc.api.tests.test_ping.PingTestCase.test_it_works

# Verbose output (shows each test name)
.venv\Scripts\python.exe manage.py test hc.api --verbosity=2

# Keep the test database between runs (faster after first run)
.venv\Scripts\python.exe manage.py test --keepdb

# Run the development server
.venv\Scripts\python.exe manage.py runserver
```
